## Описание

Небольшое интерактивное приложение на HTML, CSS и обычном JavaScript (без фреймворков).
Работает с тестовым API [JSONPlaceholder](https://jsonplaceholder.typicode.com/):

- **GET** `/posts?_limit=5` — загрузка и вывод 5 публикаций (заголовок и текст);
- **POST** `/posts` — создание публикации (`{title, body, userId: 1}`, `Content-Type: application/json`), вывод заголовка и ID из ответа.

JSONPlaceholder только имитирует создание записей: после перезагрузки страницы они не сохраняются.

## Запуск

**Вариант 1 (локально).** Скачать/клонировать репозиторий и открыть `index.html` в браузере двойным щелчком. Сервер и сборка не нужны, нужен доступ в интернет.

**Вариант 2 (VS Code).** Расширение *Live Server* → «Open with Live Server».

**Вариант 3 (GitHub Pages).** Репозиторий → *Settings* → *Pages* → *Build and deployment* → Source: *Deploy from a branch* → ветка `main`, папка `/ (root)` → *Save*. Через 1–2 минуты сайт откроется по ссылке выше.

## Результаты проверки

| № | Сценарий | Результат |
|---|---|---|
| 1 | Нажать «Загрузить публикации» | Выводятся 5 публикаций с заголовком и текстом, сообщение «Загружено публикаций: 5.» |
| 2 | Отправить пустые поля или одни пробелы | Поля подсвечиваются, выводится ошибка, запрос не отправляется |
| 3 | Отправить корректные заголовок и текст | Ответ HTTP 201, карточка с заголовком и ID (101) появляется в списке, форма очищается, выводится сообщение об успехе |
| 4 | Заменить адрес GET на `.../postz` (404) | Сообщение «Ресурс не найден (HTTP 404)…», кнопка снова активна; адрес затем восстановлен |
| 5 | Отключить интернет и нажать кнопку | Сообщение о проблеме с соединением, кнопка снова активна |

Во время запросов показывается сообщение «Загрузка…» / «Отправка…», кнопка блокируется и разблокируется в блоке `finally`.
